          Questions reviewers ask first

          Short answers with the page that backs each one.

          Is Genie sending only metadata to an LLM?

          No. Databricks lists the prompt, table and column names and descriptions, relevant data values, instructions, and example SQL. Agent mode, Genie One, and Genie Code can also send query results, cell outputs, or table samples. All of it respects Unity Catalog permissions, with one documented exception: Prompt Matching values use the author's permissions. Read: what data reaches an LLM

          Which model answers: OpenAI, Anthropic, or Google?

          It depends on the feature, the mode, and the cloud. Chat mode uses the Azure OpenAI service, with OpenAI on Databricks added on AWS and GCP. Agent mode and Genie One use Anthropic on Databricks. Google Gemini is not a host for Genie assistive features; it is a model you can select elsewhere. Read: model providers by cloud

          Do the model partners keep or train on our data?

          Databricks states partners use zero-data-retention endpoints, including no retention for abuse monitoring, and that your data is not used to train foundation models offered to third parties. Databricks itself stores conversation history, encrypted. Read: metadata, retention, and training

          Can we keep processing inside our country or Geo?

          Your tables and SQL stay in your region. Model processing follows the Geo setting. Where a Geo has no native endpoint, the feature works only with cross-Geo processing on, and enforcing the Geo turns it off. Decide first whether your policy forbids processing or only storage outside the country. Read: sovereignty and Geos

          Can a user see more through Genie than they can see directly?

          Not through interactive use: queries run as the user, and row filters and column masks apply before anything is sampled. The risks are configuration: a shared service principal on the API, secrets in instructions, Prompt Matching values generated by a highly privileged author, and views over masked tables. Read: access control and governance

          What happens when a model provider or region is unavailable?

          There is no user model picker for assistive features, and no Genie-specific SLA or recovery target is published. Plan fallbacks such as certified dashboards, and put the questions to your account team. Read: resiliency and availability
